# 🚗 Deep Learning Autonomous RC Car Project

**한국어** | [日本語](README.md)

## 📌 Project Overview

카메라 영상만으로 주행하는 엔드투엔드(End-to-End) 자율주행 RC카 개발

- **진행 기간**: 2023년 3월 ~ 2023년 6월 (대학교 4학년 1학기)
- **팀 구성**: 4명 (중간에 1명이 이탈하여 3명이 역할을 다시 나눠 개발)
- **담당 역할**
  - 학습 데이터 수집 코드 구현 (`Collection.py`, 전처리 포함)
  - 자율주행 코드 구현 및 조정 (`Driving.py`)
  - 주행 불량 원인 조사 및 카메라 각도 변경 제안
- **성과**
  - 연습용 트랙 완주
  - 모델 결정계수(R²): 66% → 82.15% (팀 단위 데이터 추가 수집 및 하이퍼파라미터 조정)
  - 학습 데이터: 약 43,000장 (학습 34,765장 / 검증 8,692장)

> Note: 자세한 실험 데이터와 분석 결과는 첨부한 [`Report.pdf`](RC_CAR/docs/Report.pdf)를 참고해 주세요.

## 🛠 Tech Stack

- **Hardware**: Raspberry Pi, 카메라, RC카 섀시
- **Software**: Python, OpenCV, TensorFlow/Keras
- **Model**: NVIDIA DAVE-2 기반 CNN (모델 구조·하이퍼파라미터는 지도교수님이 제공한 코드 사용)

## 📂 Source Code

### 1. 데이터 수집 및 전처리 (`Collection.py`) [담당]

키보드로 RC카를 수동 주행하며 카메라 이미지와 조향 라벨(좌·직진·우)을 저장.
아래 전처리를 구현했다.

- 이미지 하단 절반(노면) 잘라내기
- YUV 색공간으로 변환
- 200×66으로 리사이즈
- 카메라가 왼쪽을 많이 비추기 때문에 왼쪽 끝 약 10%를 잘라냄 (모델 입력은 66×180)
- 가우시안 블러
- 이진화 (임계값 160)

### 2. 모델 학습 (`making_model.ipynb`)

지도교수님이 제공한 코드를 바탕으로 학습. CNN으로 특징을 추출하고, 완전연결층에서 조향각을 회귀 예측한다.
평균제곱오차(MSE)와 결정계수(R²)로 평가.

### 3. 자율주행 제어 (`Driving.py`) [담당]

학습된 모델(`lane_navigation_final.h5`)을 불러와, 추론한 조향각을 좌·직진·우 3단계로 나눠 모터를 제어.

카메라 장착 위치를 바꾸면서 보드의 앞뒤가 뒤집혔기 때문에, 데이터 수집·주행 코드의 모터 구동 방향을 수정했다.

### 4. 사람 감지 시 정지 기능 (`stop_when_detec_person.py`) ※미탑재

사람을 감지하면 정지하는 기능의 프로토타입 (OpenCV DNN + 사전 학습된 객체 탐지 모델, 스레드 처리).
Raspberry Pi의 처리 성능으로는 주행에 지연이 생겨, 주행 안정성을 우선해 탑재하지 않았다.

## 💡 Trouble Shooting

### 문제: 특정 커브에서 항상 코스를 이탈

팀에서는 처음에 차체 고장을 의심했지만, "특정 위치에서만 발생한다"는 점에서 데이터 쪽에 원인이 있다고 판단했다.

### 원인 조사

촬영한 주행 이미지 약 2,000장을 한 장씩 육안으로 확인.
천장 형광등 빛이 바닥에 반사되어 이진화 후 이미지에 선처럼 찍혔고, 이를 차선으로 잘못 인식하고 있었다는 것을 찾아냈다.

### 대응

카메라를 아래쪽으로 향하게 해 반사광이 찍히지 않도록 하는 방안을 팀에 제안했고, 채택되었다.
이후 팀에서 데이터를 다시 수집했고, 연습용 트랙을 완주할 수 있게 되었다.

## 💭 Retrospective

1. **환경 변화에 대한 일반화**
   연습용 트랙에서는 안정적으로 주행했지만, 실제 평가용인 직각이고 폭이 넓은 코스에서는 정확도가 크게 떨어졌다. 그런 코스의 학습 데이터를 수집하지 않았던 것이 원인이다. 지금이라면 주행 환경을 고려한 데이터 수집 계획과 밝기 변경·노이즈 추가 같은 데이터 증강으로 일반화 성능을 높일 것이다.

2. **엣지에서의 추론**
   처리 성능 부족으로 사람 감지 기능은 보류했지만, TensorFlow Lite로 모델을 경량화·양자화했다면 Raspberry Pi에서도 두 기능을 함께 돌릴 수 있었을 가능성이 있다.

3. **데이터의 질**
   카메라 각도 조정이라는 물리적인 조치로 데이터 품질이 개선된 경험을 통해, 모델을 복잡하게 만들기 전에 데이터부터 확인하는 것이 중요하다는 것을 배웠다.
